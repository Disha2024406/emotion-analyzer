📡 How It Works

This app calls the Groq API directly from your browser — no backend needed.

Architecture
No backend server needed. Your API key is stored in sessionStorage (cleared when you close the tab). All requests go directly from your browser to api.groq.com — Groq supports CORS from browsers natively, so no special headers are required.
File Structure
# Project layout emotionai/ ├── index.html # Main HTML shell ├── css/ │ └── styles.css # All design tokens & component styles └── js/ ├── config.js # Emotion data, constants, system prompt, model ├── api.js # Groq API calls (streaming SSE) ├── ui.js # DOM rendering helpers ├── mic.js # Web Speech API integration └── app.js # Main entry point, event wiring
Groq API Call (Streaming)
const res = await fetch('https://api.groq.com/openai/v1/chat/completions', { method: 'POST', headers: { 'Authorization': `Bearer ${YOUR_GROQ_KEY}`, 'Content-Type': 'application/json', }, body: JSON.stringify({ model: 'llama-3.3-70b-versatile', max_tokens: 300, temperature: 0.1, stream: true, messages: [ { role: 'system', content: SYSTEM_PROMPT }, { role: 'user', content: text }, ], }) }); // Stream delta format (OpenAI-compatible): // parsed.choices[0].delta.content
Swap Model — edit js/config.js
// Available Groq models: export const MODEL = 'llama-3.3-70b-versatile'; // ← best quality // export const MODEL = 'llama-3.1-8b-instant'; // ← fastest // export const MODEL = 'mixtral-8x7b-32768'; // ← good balance
⚠️ Security Notes
• Your API key is stored only in sessionStorage — never sent to any third-party server.
• Keys are cleared when you close the browser tab.
• For production, proxy requests through your own backend to keep the key secret.
• Get your free Groq key at console.groq.com.
